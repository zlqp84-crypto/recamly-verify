# Recamly 진본 확인

Recamly Stamp 앱으로 찍은 사진·영상이 원본 그대로인지 확인하는 웹페이지예요.

- 주소: https://zlqp84-crypto.github.io/recamly-verify/
- 파일은 서버로 보내지 않아요. 브라우저 안에서만 계산해요.
- 확인하는 것: 파일 지문(SHA-256), 촬영한 폰 보안 칩(안드로이드 키스토어)의 서명,
  구글 키 증명서 사슬(앱 이름·서명, 폰 변조 여부), 공공 시간 증명(RFC 3161, FreeTSA).

누구나 검증 방법을 직접 읽고 확인할 수 있도록 공개해 둔 저장소예요.
